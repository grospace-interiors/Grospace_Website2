**SEO Improvements**

1. **Page-specific metadata**
   Add unique SEO metadata for each main page:
   - Home
   - Services
   - Service detail pages
   - Packages
   - Projects
   - Project detail pages
   - Price calculator
   - Landing page
   - About

2. **Better title format**
   Example:
   - `Interior Designers in Bhopal | Grospace Interiors`
   - `Modular Kitchen in Bhopal | Grospace Interiors`
   - `Home Interior Packages in Bhopal | Grospace Interiors`

3. **Better descriptions**
   Each page should describe:
   - location: Bhopal
   - service: interiors, modular kitchen, wardrobes, full home interiors
   - value: transparent pricing, site visit, custom designs

4. **Open Graph images**
   Add social sharing images for:
   - Home
   - Services
   - Packages
   - Projects

5. **Structured data**
   Add JSON-LD schema:
   - LocalBusiness
   - HomeAndConstructionBusiness or InteriorDesignBusiness style schema
   - FAQ schema where FAQs exist
   - Service schema for service pages
   - Breadcrumb schema for inner pages

6. **Image SEO**
   - Improve `alt` text.
   - Use descriptive image names where possible.
   - Avoid generic alt like “Project.”
   - Example:
     - “Modern modular kitchen interior in Bhopal”
     - “Luxury wardrobe design by Grospace Interiors”

7. **Technical SEO**
   - Add sitemap.
   - Add robots.txt.
   - Add canonical URLs.
   - Fix metadata encoding.
   - Remove `generator: v0.app`.
   - Ensure pages have one clear H1.

8. **Performance SEO**
   - Compress large images.
   - Use local optimized images where possible.
   - Avoid too many heavy remote Unsplash images.
   - Lazy-load below-fold images.
